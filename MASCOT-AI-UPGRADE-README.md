# ReelScribe AI Assistant Upgrade

## Updated files
- `reelscribe-main/server.js`
- `reelscribe-main/public/assets/js/mascot.js`

## What was added
- Floating AI chat panel that matches the site's light SaaS aesthetic
- Groq-backed chat endpoint at `/api/mascot/chat`
- Model selection via `GROQ_CHAT_MODEL` (defaults to `openai/gpt-oss-20b`)
- Page-aware support context (current URL/title and visible error messages)
- Hinglish/English assistant instructions
- Suggested prompts for clips, transcripts, plans and troubleshooting
- Conversation history saved in browser localStorage with a clear button
- Browser speech recognition for voice input where supported
- Double-click an assistant reply to have the browser read it aloud (if speech synthesis is supported)
- Mascot animation reactions while the assistant is thinking/answering
- Basic per-session rate limiting and safe error responses

## Deployment
1. Back up your existing project.
2. Replace only `server.js` and `public/assets/js/mascot.js` with the versions in this ZIP.
3. In Render Environment, keep `GROQ_API_KEY` set privately and set:
   `GROQ_CHAT_MODEL=openai/gpt-oss-20b`
4. Deploy/restart and test the chat on `/dashboard.html`.

## Notes
- Never expose `GROQ_API_KEY` in frontend JavaScript.
- Voice input depends on browser support and microphone permission; HTTPS is normally required.
- Assistant replies are generated by an AI and can be wrong. The assistant is instructed not to claim it can make payments or change account plans.
- This ZIP passed Node.js syntax checks for both modified JavaScript files. Live API/browser end-to-end testing still needs to be done after deployment.
