API documentation

Create a key in Studio → API & webhooks and send it as a bearer token. Limit: 30 requests/minute per key. Usage counts against your plan's normal transcript and clip limits.

Authorization: Bearer rs_live_xxxxxxxxxxxxxxxx

GET /api/v1/account

Your plan and limits.

POST /api/v1/transcripts

{ "url": "https://www.youtube.com/watch?v=VIDEO_ID" } // YouTube or Instagram → 201 { "success": true, "id": "…", "source": "youtube-captions", "language": "en", "words": 1234, "transcript": "…", "segments": [{ "start": 0, "end": 2.4, "text": "…" }] }

GET /api/v1/transcripts/:id?format=json|srt|vtt|txt

Fetch a saved transcript, or download subtitles.

POST /api/v1/clips

{ "url": "https://www.youtube.com/watch?v=VIDEO_ID", "captionSettings": { "style": "Kinetic Mix", "aspectRatio": "9:16" } } → 202 { "success": true, "jobId": "…", "statusUrl": "https://reelscribe.site/api/v1/clips/…" }

GET /api/v1/clips/:jobId

Poll until status is done (typically 2–5 min). Jobs are kept 2 hours; clip files for 24 hours.

{ "status": "done", "clips": [{ "title": "…", "url": "https://…mp4", "duration": 34, "score": 82, "hook": "…", "description": "…", "hashtags": ["…"] }] }

Webhooks

Instead of polling, set a webhook URL (https only) in Studio. Events: clip.completed, clip.failed, transcript.completed. Each delivery is a JSON POST with these headers:

X-ReelScribe-Event: clip.completed X-ReelScribe-Timestamp: 1760000000 X-ReelScribe-Signature: sha256=<hex>

Verify it by computing HMAC-SHA256(secret, timestamp + "." + rawBody) and comparing it to the signature. Reject timestamps older than 5 minutes. Respond with any 2xx; failed deliveries are retried 3 times.

const sig = crypto.createHmac("sha256", SECRET).update(`${ts}.${rawBody}`).digest("hex"); const ok = crypto.timingSafeEqual(Buffer.from(sig), Buffer.from(header.replace("sha256=", "")));

Errors

Every error is { "success": false, "error": "message" } with a matching HTTP status (401 bad key, 403 plan/limit, 429 rate limit).
